# Contributing

Thanks for your interest in contributing to Tutanota CLI.

- **Before opening a large PR**, please open an issue to discuss the change so we can align on approach.
- **Code and docs:** Run `npm run build` and `npm test` before submitting. Follow existing style and patterns.
- **Understanding the codebase:** For how Tuta's APIs, wire format, and encryption work, see [docs/understanding-this-repo.md](docs/understanding-this-repo.md).
